# 學生段考學習表現分析工具（Web v3.0，七～九年級）

製作：**板橋國中 高勳頊老師**

這是一個可直接部署到 GitHub Pages 的純前端工具。Excel 檔案、學生姓名與成績只在使用者的瀏覽器中解析，不會上傳到伺服器。

## 主要功能

- 匯入 `.xlsx` 成績檔，包含舊七年級分頁與後續 Word 轉換出的八、九年級分頁。
- 自動辨識正式段考分頁，例如 `114-7A-01`、`114-7B-03`。
- 支援單人查詢：`71501`。
- 支援多人查詢：`71501, 71502, 71505`。
- 支援整班查詢：`715`。
- 支援座號範圍：`71501-71509`。
- 依各年級已匯入的段考次數自動統整：五科單科校排、總校排、班排與平均（不再強制六次）。
- 總校排趨勢圖。
- 五科相對能力雷達圖。
- 優勢科目綠色、相對弱勢科目紅色。
- 多人／整班總覽，可依座號、最近校排、趨勢排序。
- 一鍵下載合併 PDF。
- 一鍵將每位學生個別 PDF 打包成 ZIP。
- A4 單頁列印：每位學生一張 A4，支援直接 Ctrl+P 與按鈕列印／另存 PDF。
- PDF 可切換彩色或黑白影印友善模式；表格與圖表字級加大。
- 每份報表固定顯示「板橋國中 高勳頊老師製作」浮水印。

## 成績檔命名規則

正式段考分頁須符合：

`學年度-年級學期-段考次數`

例如：

- `114-7A-01`：114 學年度、七年級上學期、第一次段考。
- `114-7A-03`：114 學年度、七年級上學期、第三次段考。
- `114-7B-01`：114 學年度、七年級下學期、第一次段考。
- `114-7B-03`：114 學年度、七年級下學期、第三次段考。
- `115-8A-01`：115 學年度、八年級上學期、第一次段考（新 Word 轉換格式）。
- `116-9A-01`：116 學年度、九年級上學期、第一次段考。

`A` 代表上學期，`B` 代表下學期。

## R 欄判讀

程式會辨識 `國R、英R、數R、社R、生R` 等單科校排欄位。

為避免原始試算表欄名誤植，程式會優先檢查儲存格的 `RANK()` 公式實際引用哪一個科目分數欄。若顯示標題與公式來源不一致，畫面會提出警告，分析結果以公式實際引用科目為準。

## 能力雷達圖算法

雷達圖不是直接拿「排名數字」作圖，因為第 1 名的數字反而最小。

程式會把每次單科校排換算為 0–100 的相對能力指數，再以六次平均呈現。數值越高，代表在該次排名母體中的相對位置越前。

因此雷達圖適合用來看學生的「相對科目結構」，不應直接解讀成原始分數或絕對能力。

## GitHub Pages 部署

1. 建立一個 GitHub repository，例如 `student-score-analyzer`。
2. 將本資料夾內所有檔案上傳到 repository 根目錄，**vendor 資料夾也必須一起上傳**。
3. GitHub repository 進入 `Settings` → `Pages`。
4. Source 選擇 `Deploy from a branch`。
5. Branch 選 `main`，資料夾選 `/ (root)`。
6. 儲存後，等待 GitHub Pages 產生網址。

完成後網址通常類似：

`https://你的帳號.github.io/student-score-analyzer/`

## 本機使用

本工具沒有後端，也可以直接雙擊 `index.html` 嘗試使用。若瀏覽器的本機檔案安全設定造成限制，建議直接使用 GitHub Pages 版本。

## 檔案結構

- `index.html`：主頁面。
- `styles.css`：介面與 A4 列印樣式。
- `app.js`：Excel 解析、分析、圖表、PDF 與 ZIP 功能。
- `vendor/jszip.min.js`：瀏覽器端讀取 `.xlsx` 及產生 ZIP 所需元件。
- `.nojekyll`：避免 GitHub Pages 額外處理靜態檔案。

## 隱私原則

本程式為純前端工具：

- 不使用資料庫。
- 不呼叫成績上傳 API。
- 不把 Excel、姓名、座號或成績傳給 GitHub。
- GitHub Pages 只負責提供 HTML、CSS、JavaScript 靜態檔案。

若日後自行加入 Google Analytics、外部 API 或其他第三方服務，需重新評估學生資料與個資處理方式。

## 八、九年級成績匯入與列印（v3.0）

- 原 Excel 保留七年級歷史成績；每次取得新的 Word 成績，先使用「段考成績 Word 轉 Excel 分頁產生器」在同一 Excel 活頁簿建立 `115-8A-01`、`115-8A-02` 等新分頁。這個網站 **僅讀取 Excel**，不直接匯入 Word。
- 新分頁使用 A～P 欄：班級座號、姓名、國文、英文、數學、社會、理化、總分、平均、班排、校排、國R、英R、數R、社R、理R。
- 八、九年級可只有第一次、第二次等少於六次的紀錄；不足兩次段考時不判定整體進退步。
- 各學年度及年級分開分析，查詢 `81501` 不會自動與 `71501` 合併；避免升級或轉班造成身分誤配。
- 單科 R 欄採 Excel 公式快取名次；從 Word 推算出的單科名次應以來源名單範圍解讀，不等於學校另外公布的官方單科排名。
- Chrome / Edge 可直接 Ctrl+P：列印前會以最新查詢結果準備每人一頁的版面。請選 A4、直向、比例 100%、取消瀏覽器頁首頁尾，以獲得最佳效果。
- 「下載合併 PDF」及「個別 PDF ZIP」亦固定每位學生對應一個 A4 頁面。
